# MDReader 0.1.0

Initial preview release for macOS 14 and later, supporting Apple Silicon and Intel.

- Open and edit Markdown with Edit, Split, and Preview modes.
- Render tables and Mermaid diagrams locally with Pele.
- Organize files in projects, drag files between projects, and reopen recent files.
- Customize fonts, colors, and light/dark/system appearance.
- Print documents, restore the previous session, and open files in native tabs.
- Review changes before closing or quitting, with an unsaved-change dot in tab titles.

## Installation

Download `MDReader-0.1.0-macOS-universal.dmg`, mount it, and drag MDReader to Applications.

This preview is ad-hoc signed. It is **not Developer ID signed or notarized**, so macOS Gatekeeper may block its first launch. Do not disable Gatekeeper globally. Only use this build if you trust its source; a notarized distribution requires an Apple Developer signing identity and notarization credentials.

The matching `.sha256` file provides the download checksum. iOS source is included in the repository; this release artifact is for macOS only.
