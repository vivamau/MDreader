# MDReader 0.1.1

Preview release for macOS 14 and later, supporting Apple Silicon and Intel. Build 2.

- Adds the new minimal black-on-white app icon: an italic lowercase m with an integrated fountain-pen nib extending below the baseline.
- Includes Mac and iOS icon assets in the source project.

## Installation

Download `MDReader-0.1.1-macOS-universal.dmg`, mount it, and drag MDReader to Applications.

This preview is ad-hoc signed, **not Developer ID signed or notarized**. macOS Gatekeeper may block its first launch. The matching `.sha256` file provides the download checksum.

The DMG is for macOS only; iOS source and assets are available in the repository.
